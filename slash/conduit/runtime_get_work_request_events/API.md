# Command

/conduit runtime_get_work_request_events

## Usage

Get the raw event log for a WorkRequest (chronological).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `wrId` | string | Yes | WorkRequest ID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `conduit-mcp`
- **Tool**: `runtime_get_work_request_events`
