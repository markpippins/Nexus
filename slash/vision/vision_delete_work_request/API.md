# Command

/vision vision_delete_work_request

## Usage

Delete a work request (soft-delete via trigger).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Work request ID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `vision-mcp`
- **Tool**: `vision_delete_work_request`
