# Command

/tackle delete_ai_provider

## Usage

Delete an AI provider by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Provider ID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `delete_ai_provider`
