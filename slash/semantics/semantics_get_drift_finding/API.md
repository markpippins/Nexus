# Command

/semantics semantics_get_drift_finding

## Usage

Get a single row from semantics.drift_finding by id (drift finding (finding against a snapshot observation)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_drift_finding`
