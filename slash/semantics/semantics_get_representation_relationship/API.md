# Command

/semantics semantics_get_representation_relationship

## Usage

Get a single row from semantics.representation_relationship by id (representation relationship (fidelity/lineage between forms)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_representation_relationship`
