# Command

/nebula nebula_delete_evidence_links_by_entity

## Usage

Delete all evidence links for a given knowledge entity (bulk delete).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `knowledgeEntityId` | string | Yes | Knowledge entity UUID whose links should be deleted |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_evidence_links_by_entity`
