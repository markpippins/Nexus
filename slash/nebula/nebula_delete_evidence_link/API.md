# Command

/nebula nebula_delete_evidence_link

## Usage

Delete a single evidence link by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Evidence link UUID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_evidence_link`
