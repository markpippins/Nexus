# Command

/semantics semantics_get_concept_relationship

## Usage

Get a single row from semantics.concept_relationship by id (concept relationship (legal pipeline shape between classes)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_concept_relationship`
