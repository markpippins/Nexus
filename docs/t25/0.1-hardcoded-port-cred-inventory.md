## Postgres credentials — hardcoded dev defaults (committed)

The literal `pguser` / `pgpass` is the hardcoded fallback DSN across the
TypeScript `*-srv` DB clients:

```
process.env.<X> || 'postgresql://pguser:pgpass@localhost:5432/nexus'
```

Affected services (≥ 12): assembly-srv, cascade-srv, conduit-srv, execution-srv,
harness-srv, kernel-srv, knowledge-srv, nebula-srv, peb-srv, role-memory-srv,
semantics-srv, tackle-srv (and others). Each is overridable via env
(`PGUSER`/`PGPASSWORD`/`PGHOST`/`PGPORT`/`PGDATABASE` or `DB_*` variants). The
literal is a dev default, not a live secret — but it is committed and shared.

## MongoDB credentials — hardcoded AND committed

  `MONGO_INITDB_ROOT_PASSWORD=somePassword` (weak, committed).

  `python/fs/fs-crawler/start-mongodb.sh`, `scripts/bash/start-mongodb.sh`,
