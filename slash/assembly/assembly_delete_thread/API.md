# Command

/assembly assembly_delete_thread

## Usage

Delete a thread (post) by id

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `post_id` | string | Yes | Post UUID |

## Returns

JSON object with the tool's response content.
