# Command

/tackle delete_ai_harness

## Usage

Delete an AI harness by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Harness ID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `delete_ai_harness`
