# Command

/peb peb_get_decision

## Usage

Get a single architecture decision by ID or ADR number.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Decision UUID or ADR number (e.g. ADR-001) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `peb-mcp`
- **Tool**: `peb_get_decision`
