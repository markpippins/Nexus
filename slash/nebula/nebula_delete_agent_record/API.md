# Command

/nebula nebula_delete_agent_record

## Usage

Delete an agent record from the database.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Agent record UUID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_agent_record`
