# Command

/tackle get_ai_model

## Usage

Get a single AI model by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Model ID (e.g. 'mod-gpt4o') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `get_ai_model`
