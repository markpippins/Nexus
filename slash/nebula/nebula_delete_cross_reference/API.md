# Command

/nebula nebula_delete_cross_reference

## Usage

Delete a cross-reference link.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Cross-reference UUID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_cross_reference`
