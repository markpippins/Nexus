# Command

/assembly assembly_publish_harvest

## Usage

Publish a harvest transcript as a forum post in Harvest Candidates forum, linking its candidates. Creates post + artifact refs + supporting refs. Author: Rover.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `harvest_id` | string | Yes | Nebula harvest UUID |

## Returns

JSON object with the tool's response content.
