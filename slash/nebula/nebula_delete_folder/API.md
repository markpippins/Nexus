# Command

/nebula nebula_delete_folder

## Usage

Delete a folder from a system.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `folderId` | string | Yes | Folder UUID to delete |
| `systemId` | string | Yes | Parent system UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_folder`
