# Command

/tackle list_config_bundles

## Usage

List config bundles for a role. Bundles are the atomic unit of model+provider+harness+invocation config.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `role` | string | Yes | Role name |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `list_config_bundles`
