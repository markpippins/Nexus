# Command

/semantics semantics_get_representation

## Usage

Get a single row from semantics.representation by id (representation (physical form of a concept)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_representation`
