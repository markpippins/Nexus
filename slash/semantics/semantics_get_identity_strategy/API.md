# Command

/semantics semantics_get_identity_strategy

## Usage

Get a single row from semantics.identity_strategy by id (identity strategy (what identity means for a concept)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_identity_strategy`
