# Command

/ui-tools delete_link

## Usage

Delete a link or separator from the statusbar by its UUID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | UUID of the link to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `ui-tools-mcp`
- **Tool**: `delete_link`
