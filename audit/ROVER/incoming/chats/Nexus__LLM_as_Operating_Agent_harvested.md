## 1. Embodied Agency — Intelligence Exists Because It Can Act and Observe Consequences

This is the foundation for organizational intelligence: the system learns from actual outcomes, not prompt feedback.

## 3. Three-Layer Agent Economy — Compute (Energy) → Attention (Allocation) → Trust (Credit)
**Status:** `Agreed`

### Architectural Intent
Define the three-layer economy that emerges in mature agent systems: (1) Resource Economy — tokens, GPU time, API calls, disk IO, execution slots (equivalent to fuel/energy). (2) Attention Economy — decision attention as the scarce resource: which task runs first, which proposal gets reasoning time, which agent gets context allocation. Schedulers quietly become central banks. (3) Trust Economy — agents earn trust operationally through reliability and accuracy. Trust reduces oversight cost. Trusted agents consume fewer approvals. All three layers must exist for stable institutional growth.

### Requirements & Acceptance Criteria
- [ ] Three layers: Resource (energy), Attention (allocation), Trust (credit)
- [ ] Tokens = fuel, not money
- [ ] Schedulers = central banks of attention economy
- [ ] Trust reduces approval overhead — credit for agents
- [ ] All three layers must exist for stable agent society

## 4. Institutional Economy — Legitimacy as the Ultimate Currency in Agent Systems
**Status:** `Agreed`

### Architectural Intent
Recognize that once compute, tokens, trust, and attention economies exist, legitimacy becomes the ultimate currency. No matter how clever agents are, if their proposals, actions, and optimizations aren't recognized by the governance structure, they are effectively invisible. Legitimacy determines whether a proposed workflow, ontology change, or agent decision actually matters. It is the acceptance layer that gates authority. The event kernel, civil service, and token economy all become tools to enforce and calibrate legitimacy.

### Requirements & Acceptance Criteria
- [ ] Legitimacy = acceptance layer → gates authority
- [ ] Tokens = enables action, Compute = enables execution, Trust = enables autonomy
- [ ] Legitimacy = enables authority
- [ ] Event kernel, civil service, token economy enforce legitimacy
- [ ] Legitimacy infrastructure: mechanisms, approvals, flows that make authority operational
