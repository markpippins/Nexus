# Command

/vision vision_get_work_request

## Usage

Get a single work request by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Work request ID (numeric) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `vision-mcp`
- **Tool**: `vision_get_work_request`
