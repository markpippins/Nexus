# Command

/tackle seed_default_ai_config

## Usage

Seed the AI config tables with default providers, harnesses, and models if they are empty. Set force=true to overwrite existing data.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `force` | boolean | No | Overwrite existing data if true |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `seed_default_ai_config`
