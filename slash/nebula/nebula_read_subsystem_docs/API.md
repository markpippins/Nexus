# Command

/nebula nebula_read_subsystem_docs

## Usage

Read docs from all workspace directories linked to a subsystem.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subsystemId` | string | Yes | Subsystem UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_read_subsystem_docs`
