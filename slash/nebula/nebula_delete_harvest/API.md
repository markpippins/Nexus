# Command

/nebula nebula_delete_harvest

## Usage

Delete a harvest record.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Harvest UUID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_harvest`
