# Command

/tackle get_ai_harness

## Usage

Get a single AI harness by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Harness ID (e.g. 'harn-opencode') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `get_ai_harness`
