# Command

/conduit runtime_get_work_request

## Usage

Get the current folded state of a WorkRequest from its event log.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `wrId` | string | Yes | WorkRequest ID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `conduit-mcp`
- **Tool**: `runtime_get_work_request`
