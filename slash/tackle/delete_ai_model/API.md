# Command

/tackle delete_ai_model

## Usage

Delete an AI model by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Model ID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `delete_ai_model`
