# Command

/assembly assembly_get_thread

## Usage

Get a thread (post) by id, including its comments

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `post_id` | string | Yes | Post UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `assembly-mcp`
- **Tool**: `assembly_get_thread`
