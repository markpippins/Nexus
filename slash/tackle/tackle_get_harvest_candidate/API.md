# Command

/tackle tackle_get_harvest_candidate

## Usage

Get a single harvest candidate with full detail from the Nebula RMS.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Harvest candidate UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `tackle_get_harvest_candidate`
