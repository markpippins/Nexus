## 1. Five AI-Era Engineering Skills — Spec Precision, Quality Judgment, Decomposition, Failure Pattern Recognition, Trust Design
**Status:** `Agreed`

### Architectural Intent
Define five core engineering skills for the AI era: (1) Specification Precision — communicating intent to AI with extreme detail, resisting confidence-based bias from model fluency, (2) Evaluation and Quality Judgment — building systems that encode judgment and detect errors, (3) Multi-Agent Decomposition — breaking complex projects into logical workstreams treatable by separate AI agents, (4) Failure Pattern Recognition — identifying context degradation, specification drift, sycophantic confirmation, tool selection errors, cascading failures, and silent failures, (5) Trust and Security Design — defining guardrails, blast radius of errors, and human oversight points.

### Requirements & Acceptance Criteria
- [ ] Spec precision: communicate intent with extreme detail, don't rely on model inference
- [ ] Quality judgment: resist fluency-bias, build error detection systems
- [ ] Multi-agent decomposition: logical workstreams with clear handoffs
- [ ] Failure patterns: context degradation, spec drift, sycophancy, cascade, silent failure
- [ ] Trust/security: guardrails, blast radius, human oversight checkpoints
