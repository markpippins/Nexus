# Command

/assembly assembly_list_forums_by_agenda

## Usage

Get all forums linked to an agenda

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `agenda_id` | string | Yes | Nebula agenda UUID |

## Returns

JSON object with the tool's response content.
