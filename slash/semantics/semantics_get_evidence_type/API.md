# Command

/semantics semantics_get_evidence_type

## Usage

Get a single row from semantics.evidence_type by id (evidence type (vocabulary of evidence kinds)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_evidence_type`
