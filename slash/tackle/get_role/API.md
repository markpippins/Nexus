# Command

/tackle get_role

## Usage

Get a single role by ID or name from the tackle roles table.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Role UUID or name (e.g. 'engineer', 'architect') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `get_role`
