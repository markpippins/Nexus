# peb-memory-consolidation

## Purpose
Prevents Alzheimer’s-by-accumulation. Compresses long-term decision logs and active thought context to maintain a lean, high-signal PEB. Promotes stable repeated patterns into `invariants.md` and archives obsolete data.
Ensures the forensic replayability of the Execution Context.

## Input
- `decision_log.md`
- `thought_context/active_episode.md`
- `execution_context/current_run.md`

## Output
- Compressed/Refactored PEB files.
- Emptied `active_episode.md` (upon completion of a major intent).
- Execution trace archived securely to `execution_context/archive/sealed_execution_trace.<format>` (delegating serialization strategy to the runtime).
