# Command

/semantics semantics_get_owning_subsystem

## Usage

Get a single row from semantics.owning_subsystem by id (owning subsystem (fleet)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_owning_subsystem`
