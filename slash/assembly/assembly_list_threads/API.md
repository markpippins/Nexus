# Command

/assembly assembly_list_threads

## Usage

List all threads (posts) in a forum

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `forum_id` | string | Yes | Forum UUID |

## Returns

JSON object with the tool's response content.
