```
KernelState = latest(reduce(all deltas))
```

```
KernelState = latest(reduce(all deltas))
```

You now support:

```
KernelState' = reduce(deltas, policy=P)
```

```
KernelState' = reduce(deltas, policy=P)
```

WhereP changes semantics of interpretation, not raw data.
