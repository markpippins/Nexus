# Command

/nebula nebula_get_op_registry_lineage

## Usage

Show the version lineage of an intent mapping. Returns all versions in order.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Registry entry ID to get lineage for |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_get_op_registry_lineage`
