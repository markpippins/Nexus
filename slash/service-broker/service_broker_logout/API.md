# Command

/service-broker service_broker_logout

## Usage

Logout (invalidate token).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `token` | string | Yes | The auth token to invalidate |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `service-broker-mcp`
- **Tool**: `service_broker_logout`
