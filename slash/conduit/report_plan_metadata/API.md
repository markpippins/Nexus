# Command

/conduit report_plan_metadata

## Usage

Report or update metadata for a specific plan

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `description` | string | No | Optional description |
| `planId` | string | Yes | Plan ID (e.g., "0030") |
| `title` | string | No | Optional new title |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `conduit-mcp`
- **Tool**: `report_plan_metadata`
