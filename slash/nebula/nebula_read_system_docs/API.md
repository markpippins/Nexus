# Command

/nebula nebula_read_system_docs

## Usage

Read docs from all workspace directories linked to a system.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `systemId` | string | Yes | System UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_read_system_docs`
