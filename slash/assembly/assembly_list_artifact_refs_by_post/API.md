# Command

/assembly assembly_list_artifact_refs_by_post

## Usage

Get all artifact refs linked to a specific post

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `post_id` | string | Yes | Post UUID |

## Returns

JSON object with the tool's response content.
