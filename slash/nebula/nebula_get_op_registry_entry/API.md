# Command

/nebula nebula_get_op_registry_entry

## Usage

Get a single Op Mapping Registry entry by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Registry entry ID (e.g. 'INIT_SERVICE_SCAFFOLD:v1') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_get_op_registry_entry`
