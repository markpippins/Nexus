# Command

/tackle tackle_list_systems

## Usage

List all systems from the Nebula RMS with their full hierarchy (subsystems, features, folders). Useful for finding system/subsystem IDs for spawn-plan operations.

## Parameters

*No parameters required.*

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `tackle_list_systems`
