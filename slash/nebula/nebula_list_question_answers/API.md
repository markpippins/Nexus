# Command

/nebula nebula_list_question_answers

## Usage

List all answers for an open question (multi-role deliberation).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `questionId` | string | Yes | Question UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_list_question_answers`
