# Command

/assembly assembly_get_user

## Usage

Get a user by alias or id

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `alias` | string | No | Username (alias) |
| `id` | string | No | User UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `assembly-mcp`
- **Tool**: `assembly_get_user`
