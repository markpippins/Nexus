# Command

/tackle delete_config_bundle

## Usage

Delete a config bundle by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Bundle ID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `delete_config_bundle`
