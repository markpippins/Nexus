# Command

/tackle tackle_get_scheduler_entry

## Usage

Get a single agent scheduler entry by ID.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | number | Yes | Scheduler entry ID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `tackle_get_scheduler_entry`
