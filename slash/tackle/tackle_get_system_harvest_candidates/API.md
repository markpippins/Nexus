# Command

/tackle tackle_get_system_harvest_candidates

## Usage

List all harvest candidates linked to a specific system in the Nebula RMS hierarchy.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `systemId` | string | Yes | System UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `tackle-mcp`
- **Tool**: `tackle_get_system_harvest_candidates`
