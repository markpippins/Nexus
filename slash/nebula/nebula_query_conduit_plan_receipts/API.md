# Command

/nebula nebula_query_conduit_plan_receipts

## Usage

Get all receipts (state transitions) for a specific conduit plan.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `planId` | string | Yes | The plan number or ID (e.g. '0169') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_query_conduit_plan_receipts`
