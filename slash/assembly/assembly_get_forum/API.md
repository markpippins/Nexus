# Command

/assembly assembly_get_forum

## Usage

Get a forum by slug

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `slug` | string | Yes | Forum slug (e.g. 'general-discussion') |

## Returns

JSON object with the tool's response content.
