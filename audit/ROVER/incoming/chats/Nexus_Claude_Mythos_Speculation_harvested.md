## 1. AI Security Capability Threshold — General Reasoning Improvements Produce Cyber Offense Capability
**Status:** `Observed`

### Architectural Intent
Frontier models have crossed a threshold where advanced vulnerability discovery and exploit development emerge naturally from general reasoning improvements, not explicit security training. Claude Mythos Preview demonstrated autonomous discovery of zero-day vulnerabilities across major OS and browsers, including a 27-year-old OpenBSD bug and 16-year-old FFmpeg vulnerability. Capability was not explicitly trained — it emerged from general coding improvements. This means every future frontier model will likely cross this line, making containment a governance problem rather than a prevention problem.

### Requirements & Acceptance Criteria
- [ ] Cyber capability emerges from general coding improvements, not security-specific training
- [ ] Autonomous zero-day discovery demonstrated in major OS and browsers
- [ ] Containment becomes governance, not prevention
- [ ] Defenders must automate at the same rate as attackers
- [ ] AI auditing becomes continuous, not periodic

## 2. Project Glasswing Model — Restricted Access with Coordinated Defense Before Public Release
**Status:** `Observed`

### Architectural Intent
Define the Project Glasswing model for managing frontier model release: restricted access to defenders first, coordinated disclosure, working with major security organizations (AWS, Apple, Cisco, Crowdstrike, Google, Microsoft, Nvidia, etc.) before broad release. Anthropic committed usage credits for defensive purposes and direct donations to open source security organizations. The model stays internal until safeguards are proven at scale on a less powerful model first. This creates a 'defense first' release cadence that prioritizes institutional safety over market access.

### Requirements & Acceptance Criteria
- [ ] Restricted access to defensive organizations first
- [ ] Coordinated disclosure across security ecosystem
- [ ] Safeguards proven on less powerful model before releasing more capable one
- [ ] Usage credits for defensive research
- [ ] Centralization of intelligence risk — gap between internal and public capability
