# Command

/terrain terrain_is_running

## Usage

Quickly check whether a named service or MCP server has ONLINE status. Returns true/false.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | string | Yes | Service name (e.g. 'conduit-mcp', 'nebula-srv') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `terrain-mcp`
- **Tool**: `terrain_is_running`
