# Command

/nebula nebula_get_system_info

## Usage

Get all info tab content for a system.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `systemId` | string | Yes | System UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_get_system_info`
