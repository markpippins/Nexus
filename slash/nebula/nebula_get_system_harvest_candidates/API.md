# Command

/nebula nebula_get_system_harvest_candidates

## Usage

List all harvest candidates linked to a specific system (filtered by system_id). Returns candidates with their hierarchy links and harvest source.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `systemId` | string | Yes | System UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_get_system_harvest_candidates`
