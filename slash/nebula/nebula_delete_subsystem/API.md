# Command

/nebula nebula_delete_subsystem

## Usage

Delete a subsystem and its features and requirements (cascade).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Subsystem UUID |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_subsystem`
