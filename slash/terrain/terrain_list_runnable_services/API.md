# Command

/terrain terrain_list_runnable_services

## Usage

List all registered runnable services (Express, Bun, Spring Boot, UI apps, etc.) with ports, status, and health check URLs.

## Parameters

*No parameters required.*

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `terrain-mcp`
- **Tool**: `terrain_list_runnable_services`
