# Command

/nebula nebula_delete_projection

## Usage

Delete a projection config.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Projection UUID to delete |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_delete_projection`
