# Command

/semantics semantics_get_representation_identity

## Usage

Get a single row from semantics.representation_identity by id (representation identity (how a form expresses its concept's identity)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_representation_identity`
