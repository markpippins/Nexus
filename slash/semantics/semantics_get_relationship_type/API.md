# Command

/semantics semantics_get_relationship_type

## Usage

Get a single row from semantics.relationship_type by id (relationship type (vocabulary of legal edge types)).

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Row UUID (or smallint key) |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `semantics-mcp`
- **Tool**: `semantics_get_relationship_type`
