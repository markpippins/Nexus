# Command

/nebula nebula_render_projection

## Usage

Execute a projection and write output markdown files to the audit/ folder.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | string | Yes | Projection UUID to render |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_render_projection`
