# Command

/assembly assembly_list_artifact_threads

## Usage

Get all threads (posts) linked to a specific domain artifact

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `artifact_id` | string | Yes | Artifact UUID |
| `artifact_type` | string | Yes | Type of domain artifact |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `assembly-mcp`
- **Tool**: `assembly_list_artifact_threads`
