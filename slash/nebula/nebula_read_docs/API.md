# Command

/nebula nebula_read_docs

## Usage

Read README.md and ARCHITECTURE.md from a workspace directory on disk.

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspacePath` | string | Yes | Relative path from nexus root (e.g. 'typescript/nebula-mcp') |

## Returns

JSON object with the tool's response content.

## Source

- **MCP Server**: `nebula-mcp`
- **Tool**: `nebula_read_docs`
