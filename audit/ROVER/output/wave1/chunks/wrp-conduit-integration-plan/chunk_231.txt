# 1) Decide whetherEXECUTESis the right relation from Traversal → DAG

Right now I modeled:

- wrp-v1_2-traversalEXECUTESwrp-v1_1-dag
wrp-v1_2-traversalEXECUTESwrp-v1_1-dag

That is directionally sensible if you read it as:

> “the traversal engine executes graphs defined by the DAG model.”

“the traversal engine executes graphs defined by the DAG model.”

But there are reallythree different semantic relationshipshiding in there:

## A. structural dependency

Traversaldepends onthe DAG representation.

## B. runtime operation

Traversalexecutesgraph instances that conform to the DAG model.

## C. representation pressure

Traversalconstrainswhat metadata the DAG must expose.

So if you want the bootstrap graph to stay conceptually crisp, I’d keepall threebut treat them differently:

### Recommended minimal stable set

- Traversal → DAG =DEPENDS_ON
Traversal → DAG =DEPENDS_ON

- Traversal → DAG =CONSTRAINS
Traversal → DAG =CONSTRAINS

### Optional if you want runtime semantics in the knowledge graph

- Traversal → DAG =EXECUTES
Traversal → DAG =EXECUTES

- keepEXECUTESifNebula is going to model operational semantics and not just design dependency
